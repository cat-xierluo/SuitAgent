# deepresearch

**版本**: 2.3.0
**最后更新**: 2026-01-05
**说明**: 智能法律深度研究工具，支持任意材料输入，使用独立Subagent进行深度检索

## 命令功能概述

智能法律深度研究工具，自动分析材料并生成系统化研究文档。支持任意材料输入（聊天记录、法律服务方案、案例、条文等），通过**并行启动多个独立Subagent**使用 Claude Code 内置搜索工具进行深度检索，形成精简的研究知识库。

## 核心特性

### 🎯 并发 Subagent 架构

- **并行处理**：每个研究课题启动独立的 general-purpose Subagent
- **聚焦问题**：每个 Subagent 仅解决一个核心问题
- **精简检索**：每个 Subagent 进行 4-6 轮检索（够用即可）
- **内置工具**：使用 Claude Code 内置搜索工具（WebSearch/WebFetch，无需配置）

### 📊 统一深度研究

- **任意输入**：聊天记录、法律服务方案、案例描述、法律条文等
- **统一输出**：标准化的深度研究文档
- **智能识别**：自动提取研究课题

### 📄 标准化输出

- **精简文档**：每个课题聚焦解决单一问题，简洁明了
- **总览文档**：核心结论 + 和解/策略建议 + 立即行动
- **内嵌链接**：所有来源链接直接嵌入正文
- **适度引用**：每个文档引用关键来源，够用即可

### 🗂️ 集成架构

- **12层目录集成**：输出到 `03 - 🔍 法律研究/` 目录
- **统一编号**：`YYMMDD 课题名称.md` 格式
- **并发执行**：多个 Subagent 同时工作，避免顺序等待

### 🔧 内置搜索工具

- **无需配置**：直接使用 Claude Code 内置搜索工具（WebSearch/WebFetch）
- **稳定可靠**：不依赖外部 MCP 服务器
- **智能选择**：根据需要自动选择 WebSearch（搜索发现）或 WebFetch（获取完整内容）

## 输入格式

### 使用方式

**方式一：基于文件**

```
/deepresearch @文档路径.md
```

**方式二：直接粘贴**

```
/deepresearch
[粘贴材料内容]
```

**方式三：指定案件和课题**

```
/deepresearch
案件：[案件名称]
研究课题：
1. [课题一]
2. [课题二]
3. [课题三]
```

## 处理流程

### 阶段1：分析准备（主 Agent）

1. 读取输入材料
2. 提取研究课题清单
   - 有明确课题：直接使用
   - 无明确课题：自动从材料中提取
3. **课题拆分原则**：
   - **方向明确**：每个课题对应独特的检索方向
   - **避免重叠**：确保课题之间检索关键词不重复
   - **聚焦问题**：每个课题解决一个具体问题
4. 确定案件信息和输出位置
5. 创建目录结构：`[案件编号]/03 - 🔍 法律研究/`

### 阶段2：并行深度研究（多个独立 Subagent）

**为每个研究课题启动独立的 general-purpose Subagent**

每个 Subagent 执行以下任务：

**深度检索（4-6轮）**：

- **明确检索范围**：根据研究课题确定独特的检索方向
- **避免重叠**：每个 Subagent 专注于不同的关键词和角度
- **关键词差异化示例**：
  - 课题"版本差异"：搜"SOLIDWORKS版本价格"、"标准版vs白金版"、"版本认定"
  - 课题"赔偿计算"：搜"著作权法赔偿标准"、"实际损失计算"、"法定赔偿"
  - 课题"使用程度"：搜"软件使用日志取证"、"Windows事件分析"、"数字取证"
  - 课题"类似案例"：搜"达索系统判决"、"SolidWorks侵权案例"、"苏州法院"
- **工具选择**：自动使用 WebSearch 搜索发现，WebFetch 获取完整内容

**上下文传递**（主 Agent → Subagent）：

- 案件关键信息（当事人、争议金额、核心争议点）
- **明确的检索范围**：本课题应该搜什么
- **避免重复的范围**：其他课题会覆盖什么
- 案件具体情况：让检索更贴近实际需求

**文档生成**：

- 生成精简聚焦文档，长度不限但要简洁
- 聚焦解决单一核心问题
- 包含关键来源链接（数量不限，够用即可）
- 提供直接可用的结论和建议
- **核心原则**：能够解决问题就行，不需要太详尽

**输出格式**：

- 文件名：`YYMMDD 课题名称.md`
- 保存位置：`[案件编号]/03 - 🔍 法律研究/`

### 阶段3：整合输出（主 Agent）

1. 生成研究总览文档（000.研究总览.md）
2. 整合所有 Subagent 的核心发现
3. 创建文档间导航链接
4. 添加综合策略建议和立即行动清单
5. 标注完成状态

## 注意事项

### 严禁行为

- ❌ 不创建二级子目录（如"引用素材/"）
- ❌ 不生成独立的执行总结文件
- ❌ 不使用过度罗列的要点格式
- ❌ 不在文末单独列出引用来源
- ❌ 不添加冗余的进度跟踪章节

### 推荐做法

- ✅ 使用叙述式段落表达
- ✅ 链接内嵌到相应正文位置
- ✅ 保持简洁的研究总览
- ✅ 提供具体的行动建议
- ✅ 标注清晰的文档编号
