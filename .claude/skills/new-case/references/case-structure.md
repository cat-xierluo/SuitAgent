# 案件目录结构规范

## 标准12层目录结构

```
[案件编号] 案件名称/
├── 00 - 📅 日程管理/
├── 01 - 🤝 委托材料/
├── 02 - 📄 案件分析/
├── 03 - 🔍 法律研究/
├── 04 - 📤 客户提供/
├── 05 - 📎 证据材料/
├── 06 - 📝 法律文书/
├── 07 - 📥 对方提交/
├── 08 - 🏛️ 法院送达/
├── 09 - 🎯 庭审笔录/
├── 10 - 📊 综合报告/
└── 11 - 📚 参考文件/
```

## 目录职责

| 目录 | Agent | 职责 |
|------|-------|------|
| `00 - 📅 日程管理` | Scheduler | 期限管理、工时统计 |
| `01 - 🤝 委托材料` | Writer | 委托合同、授权书 |
| `02 - 📄 案件分析` | DocAnalyzer, Strategist | 案件分析、策略 |
| `03 - 🔍 法律研究` | IssueIdentifier, Researcher | 争议焦点、法条检索 |
| `04 - 📤 客户提供` | DocAnalyzer | 客户材料 |
| `05 - 📎 证据材料` | EvidenceAnalyzer | 证据分析、质证 |
| `06 - 📝 法律文书` | Writer | 起诉状、答辩状等 |
| `07 - 📥 对方提交` | DocAnalyzer, EvidenceAnalyzer | 对方材料 |
| `08 - 🏛️ 法院送达` | DocAnalyzer, Scheduler | 传票、判决书 |
| `09 - 🎯 庭审笔录` | DocAnalyzer, Summarizer | 庭审记录 |
| `10 - 📊 综合报告` | Summarizer, Reporter | 案件摘要、报告 |
| `11 - 📚 参考文件` | Researcher | 参考案例、法条 |

## 材料分类映射

| 原始材料类型 | 目标目录 |
|-------------|---------|
| 身份证、营业执照 | `04 - 📤 客户提供/` |
| 设计图、产品图 | `04 - 📤 客户提供/` |
| 侵权截图、聊天记录 | `05 - 📎 证据材料/` |
| 合同、发票 | `05 - 📎 证据材料/` |
| 委托合同、授权书 | `01 - 🤝 委托材料/` |
| 法律服务方案、聊天记录 | `02 - 📄 案件分析/` |
| 起诉状、答辩状 | `06 - 📝 法律文书/` |
| 判例、法规链接 | `11 - 📚 参考文件/` |

## 核心文件

| 文件 | 位置 | 说明 |
|------|------|------|
| 案件信息.md | 根目录 | 案件管理看板，AI首要上下文 |
| 工时记录.md | `00 - 📅 日程管理/` | 详细工时记录 |
| .yaml | `00 - 📅 日程管理/` | 结构化期限管理 |
