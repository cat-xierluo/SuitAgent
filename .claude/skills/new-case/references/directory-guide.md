# 12层目录结构详细说明

> 整合自原 `.claude/templates/case-templates/` 各目录 README

## 00 - 📅 日程管理

- **功能**: 案件时间线、法定期限、工时统计、进度管理
- **Agent**: Scheduler
- **核心文件**: `[案件编号].yaml`（数据核心）、`[案件编号]工时记录.md`（详细记录）
- **子目录**: 工时记录/、期限提醒/、日程安排/、任务清单/、费用跟踪/

## 01 - 🤝 委托材料

- **功能**: 从委托洽谈到正式签订委托的所有材料
- **Agent**: Writer
- **核心文件**: 法律服务方案模板.md
- **子目录**: 委托合同/、授权书/、谈话笔录/、服务质量监督卡/、送达地址确认书/、初步法律意见书/、委托材料清单/
- **输出示例**: `000委托文件清单.docx`、`004委托代理合同.docx`、`005授权委托书.docx`

## 02 - 📄 案件分析

- **功能**: 案件初始分析、当事人信息、诉讼请求提取
- **Agent**: DocAnalyzer、Strategist
- **子目录**: 案件分析报告/、争议焦点分析/、SWOT分析/、诉讼策略方案/、风险评估报告/、当事人信息表/
- **输出示例**: `案件分析报告_YYYYMMDD.md`、`SWOT分析_YYYYMMDD.md`、`诉讼策略方案_YYYYMMDD.md`

## 03 - 🔍 法律研究

- **功能**: 争议焦点识别、法条检索、判例研究（核心前置，为策略和文书提供法理基础）
- **Agent**: IssueIdentifier、Researcher
- **子目录**: 争议焦点分析/、法条检索/、判例研究/、学术观点/、法律适用分析/
- **工作流**: 案件分析(02)完成 → IssueIdentifier + Researcher 并行 → 法律研究完成 → 策略制定(02)
- **输出示例**: `争议焦点分析_YYYYMMDD.md`、`法条检索报告_YYYYMMDD.md`、`判例研究报告_YYYYMMDD.md`

## 04 - 📤 客户提供

- **功能**: 客户主动提供的所有材料（除委托文件外）
- **Agent**: DocAnalyzer
- **子目录**: 初始材料/、补充材料/、客户反馈/、沟通记录/、需求确认书/、客户指示/
- **输出示例**: `初始材料_YYYYMMDD.md`、`补充材料_YYYYMMDD.md`、`客户反馈_YYYYMMDD.md`

## 05 - 📎 证据材料

- **功能**: 证据目录、质证意见、证据分析报告
- **Agent**: EvidenceAnalyzer
- **子目录**: 证据清单/、质证意见/、证据分类/（书证/物证/电子证据/证人证言/鉴定意见）、补充证据建议/、证据保全申请/
- **输出示例**: `证据目录_YYYYMMDD.xlsx`、`质证意见书_YYYYMMDD.md`、`证据三性分析_YYYYMMDD.md`

## 06 - 📝 法律文书

- **功能**: 律师起草的所有法律文书，按类型分类
- **Agent**: Writer（支持15种文书类型）
- **子目录**: 起诉状/、答辩状/、代理词/、质证意见书/、申请书/、上诉状/、律师函/、调解协议/、法律意见书/、其他文书/
- **工作流**: 法律研究(03)完成 → Writer 基于法理生成文书 → Reviewer 质量审查
- **输出示例**: `起诉状_YYYYMMDD.md`、`答辩状_YYYYMMDD.md`、`代理词_YYYYMMDD.md`

## 07 - 📥 对方提交

- **功能**: 对方当事人及其代理人提交的所有材料
- **Agent**: DocAnalyzer、EvidenceAnalyzer
- **子目录**: 起诉状/、答辩书/、反驳证据/、质证意见/、申请书/、上诉材料/、和解方案/
- **工作流**: 对方提交材料 → DocAnalyzer 分析 → 更新争议焦点 → 调整策略
- **输出示例**: `对方起诉状分析_YYYYMMDD.md`、`对方答辩书分析_YYYYMMDD.md`

## 08 - 🏛️ 法院送达

- **功能**: 法院送达的所有文书和通知
- **Agent**: DocAnalyzer、Scheduler
- **子目录**: 传票/、应诉通知书/、举证通知书/、裁定书/、判决书/、调解书/、送达回证/、缴费通知/
- **关键期限**: 应诉15天、答辩15天、举证（法院指定）、上诉15天、执行申请2年
- **输出示例**: `法院送达文书分析_YYYYMMDD.md`、`判决书分析_YYYYMMDD.md`

## 09 - 🎯 庭审笔录

- **功能**: 庭审过程记录与庭后分析
- **Agent**: DocAnalyzer、Strategist、Summarizer
- **子目录**: 庭审笔录原文/、庭后分析/、庭审摘要/、庭审策略调整/
- **工作流**: 庭审结束 → DocAnalyzer 分析笔录 → Summarizer 生成摘要 → Strategist 调整策略
- **输出示例**: `庭审笔录分析_YYYYMMDD.md`、`庭后分析报告_YYYYMMDD.md`

## 10 - 📊 综合报告

- **功能**: 案件综合分析和汇总报告
- **Agent**: Summarizer、Reporter
- **子目录**: 案件摘要/、阶段进展报告/、风险评估报告/、客户汇报/、案件总结报告/、数据统计分析/
- **数据来源**: 02案件分析、03法律研究、05证据材料、06法律文书、07对方提交、09庭审笔录、00工时统计
- **输出示例**: `案件摘要_YYYYMMDD.md`、`阶段进展报告_YYYYMMDD.md`、`客户汇报_YYYYMMDD.md`

## 11 - 📚 参考文件

- **功能**: 辅助性参考材料，提供知识和信息支持
- **Agent**: Researcher
- **子目录**: 参考案例库/、法律条文汇编/、行业标准/、学术论文/、新闻报道/、政策文件/、操作指南/
- **更新机制**: 定期更新（每月）+ 遇到新信息实时补充 + 质量筛选
